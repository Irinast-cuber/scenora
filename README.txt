SCENORA — ОБНОВЛЕНИЕ САЙТА

Сохраните оригинальный index.html без изменений и загрузите рядом с ним:
- scenora-extra.css
- scenora-extra.js
- passport.html

В index.html добавьте ПЕРЕД строкой </head>:
<link rel="stylesheet" href="scenora-extra.css">

В index.html добавьте ПЕРЕД строкой </body> (после существующего </script>):
<script src="scenora-extra.js"></script>

Итого: 2 строки в исходном index.html, весь остальной код остаётся прежним.

Что появится:
- вместо вымышленных профилей дизайнеров — Open Call с анкетой;
- раздел Backstage с этапами создания будущих коллекций;
- блок цифрового паспорта и отдельная страница passport.html;
- предупреждение, что товары и цены в карусели демонстрационные;
- в форме демооплаты удалятся поля карты, срока и CVV.

Анкета не отправляет данные. Чтобы получать реальные заявки, нужно подключить сервис обработки форм.

Загрузите четыре файла (включая обновлённый index.html) в корень GitHub-репозитория, дождитесь публикации GitHub Pages.
Страница паспорта будет по адресу: https://irinast-cuber.github.io/scenora1/passport.html
QR-код на бирке можно делать на этот адрес после проверки публикации.
